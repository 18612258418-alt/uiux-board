目标 03 · 设计语言｜规划范围 × 进展矩阵

目标 03 · 2027.07-09 · 交互 / 视觉 / 组件 / 动效 / 适配 / 落地

01交互

  • 核心任务路径：≤ 3 步，与 iPadOS 逐条对标
  • 手势统一：返回 / 主页 / 多任务，防误触
  • 反馈时机：点击即响应，超 100ms 给加载态
  • 可撤销可回退：误操作不留死路
  • 多窗口导航：分栏与多窗口下导航层级不丢上下文

02视觉资产

  • 布局栅格：间距 / 圆角：一套值走全端
  • 色彩规则：语义色 + 深浅色 + 强调色
  • 字体系统：字号阶梯与字重配对
  • 图标体系：分层体系 + 四种外观
  • 材质 Token：玻璃 / 阴影 / 描边

03组件与状态

  • 全量组件库：导航 / 列表 / 卡片 / 弹窗
  • 状态矩阵：按下 / 禁用 / 加载 / 空 / 错误
  • 组件解耦：与业务解耦，改样式不动逻辑
  • 版本化：可增量升级

04动效体系

  • 曲线标准化：时长档位 + 缓动曲线
  • 节点与转场：系统 22 节点 + App 内 5 组转场
  • 打断降级：低性能设备策略
  • 性能预算：丢帧 ≤ 1% · 跟手 ≤ 50ms

05适配

  • 横竖屏：旋转不丢布局、不重排错位
  • 分屏 / 浮窗 / 多窗口：内容不截断
